# 小说整合包（dsh-novel-kit）

写长篇最烦的不是没灵感，是**接不上**：上一章的人、事、伏笔，写到第三十章只剩一个大概；设定、称呼、禁忌越写越乱；句子和节奏也越来越像 AI。

这个包把「事件 / 拍板 / 记忆 / 文风 / 同人世界观 / 编排」收进一个安装：装一次，就有一条从导入、计划、拍板、写作、检查到落账的完整链。

- **一条链**：计划 → 开章 → 写 → 检查 → 事务落账，中断可恢复；
- **两种入口**：学文笔只收句子与决策倾向；写同人收世界契约，必须作者确认；
- **三层开关**：总开关默认关，项目原创/同人，本会话 `/novel on`；
- **一个工作台**：书桌 / 章节 / 故事 / 资料，写、看拍板、查依据都不用来回切聊天；
- **旧五件可迁移**：先 `/novel legacy` 接管旧账本，确认内容都在，再卸载 beat / fade / voice / fanfic / conductor，避免两套执行者抢同一本账。

适合写长篇、写同人、想学某位作者写法的人。不写小说时，它不会出现在你的工具列表里。
