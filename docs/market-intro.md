# 小说工作台（dsh-novel-kit）

写长篇最烦的不是没灵感，是**接不上**：上一章的人、事、伏笔，写到第三十章只剩一个大概；设定、称呼、禁忌越写越乱；句子和节奏也越来越像 AI。

小说工作台把「剧情决策 / 世界契约 / 长篇记忆 / 文风」收成四段写作依据，每次动笔前装配好；写完先检查，再在同一个可恢复事务里落账。

- **一条链**：计划 → 开章 → 写 → 检查 → 落账，中断可恢复；
- **七页工作台**：书桌、正文、决策、记忆、风格、同人、资料，写与查依据不用来回切聊天；
- **检查能定位**：禁忌词、与原著雷同、称呼不符、文风越界，点一下选中那句；
- **两个导入口**：学文笔只收写法，写同人收世界契约并逐条审阅；
- **默认关闭**：不写小说时，它不会出现在你的工具列表里。

适合写长篇、写同人、想让 AI 写得像自己的人。
