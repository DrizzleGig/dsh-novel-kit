# 小说整合包（dsh-novel-kit）

写长篇最烦的不是没灵感，是**接不上**：上一章的人、事、伏笔，写第三章还记得，写到第三十章就只剩一个大概。

这个包把「事件 / 记忆 / 文风 / 同人 / 编排」收进一个安装：装一次，就有一套按章推进的写作引擎。

- **一章有流程**：计划 → 开始 → 写 → 收尾，收据可回查；
- **四段依据**：本章要拍板的、本书已拍板的、前情简报、文风简报，一次装配；
- **写完有检查**：禁忌词、原著复制、写错名字、文风漂移，有问题当场指出；
- **账本可追溯**：每章落账都有事务回执，改坏了能按前后镜像恢复；
- **一个开关**：`/novel on` 开，收起时不占上下文。

旧五件（beat / fade / voice / fanfic / conductor）照常单独可用；kit 装好后可以在面板里一键接管，随时恢复。
