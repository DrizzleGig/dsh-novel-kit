# 小说面板 UI v2 设计说明

## 旧界面问题

用户 2026-11-22 重启后的截图暴露了四个问题：

1. **首屏被设置占满**：总开关、项目模式、导入路径横在第一屏，真正要做的「下一笔」没有可点击主按钮；
2. **没有层级**：所有卡片同色、同边距、同字号，信息像一串数据库字段；
3. **字太小**：大量 10–11px 标签，长中文在 390px 宽右栏里读起来很累；
4. **主行动不可用**：界面提示「先选书或开一章」，但没有开章按钮；工作台按钮也无条件跳到章节。

## 信息架构

右栏默认只保留四层：

```text
品牌头 / 当前作品
↓
一张大号「下一笔」卡（唯一主行动）
↓
本章依据（四段预算）
↓
收件箱 / 最近章节
↓
设置与详情（默认关闭）
```

设置与详情里才放：总开关、原创/同人、导入、旧五件接管、六页签（总览/拍板/记忆/文风/设定/冲突）、会话与账本诊断。

工作台保持四入口：

- **书桌**：下一笔、统计、收件箱、最近章节；
- **章节**：可编辑正文 + 保存 + 依据/检查；
- **故事**：拍板记录、待拍板、线索、历史；
- **资料**：四段依据、文风、canon。

## 视觉规范

- 字体：正文 12.5–13px，卡片标题 20–22px，按钮 12.5–13px；不再用 9–10px 承载关键信息。
- 间距：页面 16px，卡片内 12–16px，卡片间 12–14px；依靠间距、边线、次级背景分层，不堆阴影。
- 圆角：卡片 12–16px，按钮 8–10px，状态胶囊 999px。
- 颜色：全部走 DSH 主题 token：
  - `--dsw-alias-bg-base` / `layer-1`
  - `--dsw-alias-label-primary` / `secondary` / `tertiary`
  - `--dsw-alias-border-l1`
  - `--dsw-alias-brand-primary`
  - `--dsw-alias-label-primary-foreground`（主按钮文字，不能用死白）
  - `--dsw-alias-state-error-primary` / `warning-primary`
- 主按钮：品牌色实心，宽度拉满，位于「下一笔」卡底部；禁用态用边框色，不假装可点。
- 暗色/浅色：只依赖宿主 token，不硬编码纸色/朱砂；品牌色仅用于强调。

## 状态

- 加载：显示「加载中」，不把空数组当成「无数据」；
- 空态：明确告诉用户下一步是「开第 N 章」或「先导入」；
- 待拍板：主行动变成「去拍板（N）」，打开详情里的拍板页；
- blocker：主行动变成「查看检查详情」；
- 有草稿：主行动是「查看本章详情」，不承诺直接跳工作台；
- 同人 canon 未确认：收件箱出现「canon 待确认」，开章会返回明确错误；
- 错误：就近显示在卡片里，不用 alert，不把失败伪装成成功。

## 已实现

- 右栏：品牌头、当前作品选择、大号下一笔卡、主行动、依据尺、收件箱、最近章节、设置折叠；
- 主行动 `chapter.start` 走作者命令，可真正开章；
- 工作台：作品头、状态胶囊、四入口、书桌主行动、章节编辑器；
- 使用 `label-primary-foreground` 等宿主 token。
